# Перенос лендинга в GetCourse

В этой папке лендинг разложен на 14 готовых кусков HTML. Каждый файл — один HTML-блок в конструкторе страниц GetCourse.

| Файл | Что внутри |
|---|---|
| `00-stili.html` | Общие стили и шрифты. **Без него остальные блоки будут без оформления** |
| `01-menu.html` | Верхнее меню с кнопкой «Подписаться» |
| `02-hero.html` | Первый экран с петухом и «Сентябрь за 60 секунд» |
| `03-riski.html` | Риски месяца |
| `04-tri-sistemy.html` | Три системы, метафоры, цитата спикера |
| `05-ba-tszy.html` | Карта Ба Цзы, таблица знаков, скрытый столп |
| `06-algoritm.html` | 3 шага и гексаграмма 31 |
| `07-kalendar.html` | Календарь месяца |
| `08-tsi-men.html` | Ци Мэнь: сферы, справочник, карта направлений |
| `09-fenshui.html` | Фэншуй: летящие звёзды и активации |
| `10-otzyvy.html` | Отзывы и цифры |
| `11-faq.html` | Вопросы и ответы |
| `12-final.html` | Финальный призыв подписаться |
| `13-podval.html` | Подвал |

`preview.html` — вся страница целиком. Откройте его двойным щелчком, чтобы посмотреть, как должно получиться.

## Как перенести

1. В GetCourse создайте новую страницу в конструкторе.
2. Добавьте HTML-блок (кнопка «Добавить блок» или «+», в списке блоков найдите «HTML»).
3. Откройте файл `00-stili.html` в Блокноте или VS Code, выделите всё (`Ctrl+A`), скопируйте (`Ctrl+C`) и вставьте в HTML-блок. Сохраните блок.
4. Добавьте под ним следующий HTML-блок и так же вставьте `01-menu.html`.
5. Повторите для всех файлов по порядку номеров, до `13-podval.html`.
6. В настройках каждого блока, если есть такие поля, уберите отступы сверху и снизу и выберите ширину «на всю ширину». У секций свои отступы и фоны.
7. Откройте страницу в режиме просмотра и сравните с `preview.html`.

Блок `00-stili.html` на странице не виден, но должен стоять выше остальных. Блоки 01–13 можно переставлять или убирать: каждый работает сам по себе.

## Что важно знать

- **Картинка петуха уже внутри блока `02-hero.html`.** Загружать её отдельно не нужно.
- **Шрифты Inter и Lora** подгружаются из Google Fonts. Если они не загрузятся, браузер покажет похожие системные шрифты.
- **Меню не прилипает к верху экрана** при прокрутке: в GetCourse каждый блок живёт в своём контейнере. Кнопки меню прокручивают к нужным разделам.
- **Мобильного «гамбургер»-меню нет**: оно работало на JavaScript. На телефоне в меню видны логотип и кнопка «Подписаться».
- **Вопросы FAQ и справочник Ци Мэнь** раскрываются без скриптов, средствами браузера.
- **Стили лендинга не трогают остальную страницу GetCourse.** Они действуют только внутри блоков.

## Заглушки, которые нужно заменить

Сейчас в блоках стоят: `[Название бренда]`, `[Имя спикера]`, `[N]` подписчиков, 3 отзыва `[Реальный отзыв…]` и ссылка `https://t.me/your_channel`.

Есть два способа их заменить:
- **Рекомендуемый:** поменять значения в `lib/site.ts` и `lib/content.ts` и пересобрать блоки командой `npm run export:getcourse`. Тогда замена пройдёт сразу во всех блоках.
- **Вручную:** в каждом HTML-блоке GetCourse найти заглушку и заменить текст. Ссылка на канал встречается в нескольких блоках.
